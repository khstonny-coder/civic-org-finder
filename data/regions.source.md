# 지역 데이터(regions.json) 출처와 만든 방법

PLAN 작업 3번에서 만든 전국 시·군·구 256곳의 목록이다. DB의 `regions` 표에 들어간다.

## 출처 (출처 표시 의무가 있다)

- **원자료**: 통계청 통계지리정보서비스(SGIS)의 행정동 경계. 공공누리 제1유형(출처표시)으로 개방된 자료이다.
- **가공 저장소**: [vuski/admdongkor](https://github.com/vuski/admdongkor) — 데이터는 CC BY 4.0 (CC BY 4.0 라이선스와 SGIS 출처표시 의무를 함께 지킨다)
  - `ver20261001/HangJeongDong_ver20261001.geojson` : 시·군·구 코드·이름과 경계(인접 지역 계산)
  - `dist/data/timeline_v3_sgg.parquet` : 시·군·구 코드·이름의 변천 기록(옛 명칭)

## 항목 설명

| 항목 | 설명 | 만든 방법 |
|---|---|---|
| `code` | 5자리 행정구역 코드 | 원자료 `sgg` 값 그대로 |
| `sido`, `sigungu` | 시·도, 시·군·구 | 원자료 이름. "수원시장안구"처럼 붙은 이름은 "수원시 장안구"로 띄움 |
| `aliases` | 약칭 (예: "경남 진주시", "서울시 마포구", "광주 동구") | 규칙으로 생성 |
| `former_names` | 행정구역 개편 전 이름 (예: "전라남도 해남군") | 변천 기록에서 확인한 개편만 넣음 |
| `neighbor_codes` | 경계가 맞닿은 인접 지역 코드 | 행정동 경계에서 시·군·구별로 꼭짓점이 약 40m 이내로 2개 이상 겹치는 쌍을 인접으로 판단 |

## 알아 둘 점

- **인접 지역은 계산 결과이다.** 경계 자료의 정밀도 때문에 맞닿은 길이가 아주 짧은 곳은 빠지거나, 반대로 잘못 들어갈 수 있다. 이웃이 아예 없는 곳은 인천 영종구, 옹진군, 울릉군이다.
- **섬 지역은 수작업으로 연결했다**: 해남-완도, 해남-진도, 통영-거제, 하동-남해, 사천-남해. (다리·좁은 바다로 이어진 곳)
- **옛 명칭의 일부는 추정이다.** 인천 구 개편(2026-07: 중구·동구·서구 → 제물포구·영종구·서해구·검단구)과 창원시 통합(2010)처럼 하나가 여러 곳으로 나뉘거나 합쳐진 경우, 어느 옛 구역이 어느 새 구역에 해당하는지는 같은 시·도 안에서 짝지은 것이다.
- 데이터는 2026-10-01 기준이다. 행정구역이 또 바뀌면 최신 자료로 다시 만들어 `npm run regions:load`로 갱신한다.
- 시 아래 구(예: 수원시 장안구)는 구 단위로 들어 있다. "수원시"로 검색하면 `sigungu`가 "수원시"로 시작하는 곳을 모두 찾으면 된다.
